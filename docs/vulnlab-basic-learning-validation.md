# 기초 학습·로컬 실습 검증

## 기존 상태

- `/learn`: IDOR 개념·간단한 코드 비교, SQL Injection 실습 링크. XSS·권한 검사는 준비 중.
- `/practice`: IDOR·SQL Injection 로컬 링크와 서버 상태 패널. 외부 서비스 설정·실행 부분은 비활성 UI.
- `labs/basic-site`: 가상 계정 3개, 메모리 세션, 사용자별 게시글, 정상 소유권 검사와 명시적 IDOR API. SQL Injection은 별도 메모리 SQLite의 실제 검색 API와 바인딩 비교를 제공.
- 두 기존 실습은 같은 커뮤니티에 6단계 가이드를 표시하며 메인 사이트에서 127.0.0.1:4400 새 탭으로 연결. 메인 인증·DB와 독립적.

## 구현

- `/learn`: 네 주제 모두 정의, 원인, 웹사이트 예시, 공격 원리, 취약·안전 코드, 예방·대응, 실습 버튼 제공.
- `/practice`: 네 실습 실행 링크와 학습 복귀 연결. 미완성 외부 서비스 실행 UI를 로컬 실습 진행 안내로 교체.
- XSS: 별도 활성화와 로그인 필요. POST 입력을 취약 HTML 또는 이스케이프한 텍스트로 생성. sandbox 프레임에서만 실행하며 alert 실행 메시지를 감지. 네트워크·쿠키·부모 DOM 접근 제한.
- 권한 검증: 별도 활성화와 로그인 필요. 취약 모드는 로그인만 검사, 안전 모드는 서버 세션의 admin 역할 검사. 읽기 전용 가상 관리자 통계만 반환.
- 네 실습 상태, 실행 명령, 연결 실패·재시도 안내 및 학습 복귀 링크 추가. 정상 커뮤니티 본문·기존 로그인·운영 DB는 유지.
- Vitest가 Node 전용 실습 테스트를 수집하지 않도록 src 테스트로 범위를 한정하고 워커를 2개로 제한. Node 실습 테스트는 별도 npm 명령으로 실행.

## 검증 결과

- 메인 및 실습 서버 TypeScript 검사 통과.
- Next.js production build 통과.
- 로컬 서버 Node 테스트 37/37 통과. 실제 HTTP·세션을 사용.
- 학습·연결 Vitest 13/13 통과. HTML 렌더링 링크, 서버 오류·타임아웃 처리 확인.
- 전체 Vitest: 712 통과, 6 실패, 5 건너뜀. 54개 파일 통과, 4개 실패, 4개 건너뜀.
- 전체 테스트의 실패는 이번에 수정하지 않은 AuthButtons(2), LabSession 메뉴 순서(1), repositoryMetadataAccess(2), learningRoles.regression의 HomePage 이름 기대(1). 인증이나 분석 기능은 범위 밖이므로 변경하지 않음.
- IDOR: A가 B의 102번 글 조회 시 취약 200/비공개 글 노출, 안전 403. 본인 글 조회 정상.
- SQL Injection: 정상 검색과 조건 우회 입력 비교. 취약 조회는 비공개 가상 글 포함, 바인딩 조회는 입력을 문자열로 처리. 쓰기·파일 접근·위험 SQL 차단 확인.
- XSS: 실제 API에서 취약 HTML 보존/안전 출력 이스케이프, 입력 길이, 로그인, 비활성 상태, sandbox·CSP 설정 확인.
- 권한 검증: 사용자 A/B 안전 403, 일반 사용자 취약 200, 관리자 안전 200. 요청 role 위조 무시.

## 남은 확인과 제한

- 브라우저 도구가 현재 URL을 신뢰할 수 있게 확인하지 못해 브라우저 자동 검증이 중단됨. 실제 브라우저의 XSS 이벤트 실행·레이아웃·페이지 이동은 수동 확인이 필요함. 자동 API·마크업 테스트를 브라우저 검증으로 간주하지 않음.
- 메인 복귀 링크는 기본 `http://localhost:3000` 사용. 다른 포트에서 메인을 실행하면 링크 조정 필요.
- 실습 결과는 현재 화면 메모리에만 유지. 새로고침하면 초기화. 운영용 기능이나 외부 프로젝트 분석은 추가하지 않음.

실행 명령과 계정은 `labs/basic-site/README.md` 참고.
